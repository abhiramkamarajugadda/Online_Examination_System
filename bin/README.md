# Online Examination System
Complete Spring Boot + JSP + MySQL project.

## Run
1. Create database: online_exam_db
2. Edit application.properties and set your MySQL password.
3. Import as Maven project in Eclipse/STS.
4. Run OnlineExaminationApplication.java.
5. Open http://localhost:8080/
